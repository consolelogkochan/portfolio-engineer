# 統一ログの置き場所

ここは、カードごとの統一ログと、セッションの引き継ぎの記録を置く場所である。

## 何を置く場所か

- カードごとの統一ログ。ファイル名は `<カード番号>-<番号>.md`（例：`7-8c-1.md`）
- 引き継ぎの記録。ファイル名は `<前>to<次>.md`（例：`7-8to7-8b.md`）

開発者が置くほか、Claude Code が依頼を受けて作ることもある。7-4i から置いているため、7-4h 以前の統一ログはここに無い。

## 正本との関係

正本はここにある（2026-10-27 に、Notion からここへ移した）。Notion にはコピーを置く。

ここだけを更新し、Notion のコピーを更新し忘れると、Notion は古いまま残る。両者を同期させる自動化は無い。

【更新（2026-11-13）】統一ログの写しは、本人のアプリ `learning-app` に作業日誌として投稿している（本人、2026-11-13）。正はリポジトリ。

## 公開しない

このディレクトリは `.gitignore` の対象であり、`README.md` を除いてコミットされない。協働の試行錯誤の集大成であり、そのまま公開・流用されることを避けるためである。

## カードの索引

- 「主な判断の記録先」は、判断の表の「記録先」の列に出てくる文書の種類を拾ったもの。手順書は `docs/server-setup.md`、台帳は `docs/ledger.md`、環境・開発者向け・運用の一覧は `docs/environment.md`・`docs/development.md`・`docs/operations.md`、コードはコミット・ファイル・コメント・テスト
