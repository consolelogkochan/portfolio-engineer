# 統一ログの置き場所

ここは、カードごとの統一ログを置く場所である。ファイル名はカード番号にする。

## 何を置く場所か

カードごとの統一ログ（例：`7-4i.md`）を置く。開発者が Notion から手でコピーして置く。Claude Code はこれを作らない。

## 正本との関係

正本は Notion にある。ここに置くのは、Claude Code がリポジトリ内のファイルとして読めるようにするための作業用コピーである。

Notion 側だけを更新し、このコピーを更新し忘れると、ここは古いまま残る。両者を同期させる自動化は無い。

## 公開しない

このディレクトリは `.gitignore` の対象であり、`README.md` を除いてコミットされない。協働の試行錯誤の集大成であり、そのまま公開・流用されることを避けるためである。
