# 協働プロトコルの置き場所

ここは、開発者と Claude Code の協働プロトコル関連の文書を置く場所である。

## 何を置く場所か

3種類を置く。いずれも開発者が Notion から手でコピーして置く。Claude Code はこれらを作らない。

- **`collaboration-protocol.md`**：協働プロトコル。進め方のルールを定めたもの
- **`handoff-prompt-spec.md`**：引き継ぎプロンプト作成規格。引き継ぎプロンプトの構造と作り方を定めたもの
- **`handoff-prompt.md`**：引き継ぎプロンプト本体。次のセッションへ渡すもの

**ファイル名は `collaboration-protocol.md` の形（英語の一般名詞、ハイフン区切り、略語を使わない）に揃える。** バージョン番号・作成日・カード番号はファイル名に含めない。規格の版が上がっても同じ場所を指せることと、「最新の1本だけを置く」という運用（上書きする。過去のものを並べて残さない）に、古い番号や日付が残る問題を持ち込まないことの両方を満たすためである。

**引き継ぎプロンプトは最新の1本だけを置く。** 過去のものは外部（Notion）にのみあり、ここには無い。たとえば 7-4 へ渡した引き継ぎプロンプト（2026-08-31 作成）はリポジトリ内には無い。

**カードごとの統一ログは `.records/` にある（ここではない）。** 7-5 から置き始めるため、7-4 以前の統一ログはリポジトリ内に無い。

## 正本との関係

正本は Notion にある。ここに置くのは、Claude Code がリポジトリ内のファイルとして読めるようにするための作業用コピーである。

Notion 側だけを更新し、このコピーを更新し忘れると、ここは古いまま残る。両者を同期させる自動化は無い。

## 公開しない

このディレクトリは `.gitignore` の対象であり、`README.md` を除いてコミットされない。協働の試行錯誤の集大成であり、そのまま公開・流用されることを避けるためである。
