# 協働プロトコルの置き場所

ここは、開発者と Claude Code の協働プロトコル関連の文書を置く場所である。

## 何を置く場所か

3種類を置く。

- **`collaboration-protocol.md`**：協働プロトコル。進め方のルールを定めたもの。正は Notion にあり、開発者がコピーして置く
- **`handoff-prompt-spec.md`**：引き継ぎプロンプト作成規格。引き継ぎプロンプトの構造と作り方を定めたもの。正は Notion にあり、開発者がコピーして置く
- **`handoff-prompt.md`**：引き継ぎプロンプト本体。次のセッションへ渡すもの。規格に従って Claude Code が作り、開発者が Notion へ写す

**ファイル名は `collaboration-protocol.md` の形（英語の一般名詞、ハイフン区切り、略語を使わない）に揃える。** バージョン番号・作成日・カード番号はファイル名に含めない。規格の版が上がっても同じ場所を指せることと、「現行と1つ前の2本を置く」という運用（現行を上書きしつつ、1つ前だけを `-previous` として残す。2本より増やさない）に、古い番号や日付が残る問題を持ち込まないことの両方を満たすためである。

**引き継ぎプロンプトは、現行の `handoff-prompt.md` と、1つ前の `handoff-prompt-previous.md` の2本を置く。2本より増やさない。** 理由：2章（プロジェクトの背景）と9章（関わり方の前提）の転記元が必要であり、`.gitignore` 対象のため git からは戻せないため。それより前のものは外部（Notion）にのみあり、ここには無い。たとえば 7-4 へ渡した引き継ぎプロンプト（2026-08-31 作成）はリポジトリ内には無い。

**カードごとの統一ログは `.records/` にある（ここではない）。** 7-4i から置いているため、7-4h 以前の統一ログはリポジトリ内に無い。

## 正本との関係

協働プロトコルと規格の正本は Notion にある。ここに置くのは、Claude Code がリポジトリ内のファイルとして読めるようにするための作業用コピーである。Notion 側だけを更新し、このコピーを更新し忘れると、ここは古いまま残る。

引き継ぎプロンプトは、ここで Claude Code が作り、開発者が Notion へ写す。写し忘れると、Notion が古いまま残る。

どちらの向きも、同期させる自動化は無い（2026-10-27 に、引き継ぎプロンプトの作り手を今の事実に直した）。

## 公開しない

このディレクトリは `.gitignore` の対象であり、`README.md` を除いてコミットされない。協働の試行錯誤の集大成であり、そのまま公開・流用されることを避けるためである。**そのため、ここにあるファイルは git の履歴からは戻せない**（規格の冒頭「置き場所」と同じ）。
